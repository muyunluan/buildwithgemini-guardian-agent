# Agent Spec: Weather Agent

## Overview
A simple ADK agent designed for local testing that retrieves mock weather and current time information for cities using Python function tools.

## Example Use Cases
- User asks: "What is the weather in Tokyo?" -> Agent calls `get_weather(city="Tokyo")` and returns weather details.
- User asks: "What time is it in London?" -> Agent calls `get_time(city="London")` and returns current time.

## Tools Required
- `get_weather(city: str) -> str`: Returns mock weather forecast for a specified city.
- `get_time(city: str) -> str`: Returns current time for a specified city.

## Constraints & Safety Rules
- Handles unknown cities gracefully with default/informative fallback output.
- Clean formatting of weather and time results.

## Success Criteria
- Correct tool execution on weather and time queries.
- Clean, clear responses formatted nicely.
